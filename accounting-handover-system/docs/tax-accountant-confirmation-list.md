# 税理士確認事項リスト

このシステムの勘定科目・税区分はすべて**候補(初期案)**であり、確定していません。
以下を顧問税理士に確認し、回答を `07_確認・質問管理` に記録 → `06_書類処理ルール` へ反映してください。
確認が済んだ項目はチェックを入れ、回答の要点を追記します。

## 事業区分

- [ ] **法人と個人事業の経費区分**: どの支出をどちらに計上するか。判断基準と迷ったときの扱い
- [ ] **店舗間振替**: 店舗間での材料・資金のやり取りの処理方法
- [ ] **家事按分**: 代表の自宅兼用費用(通信費・車両等)の按分割合と根拠

## 勘定科目・税区分

- [ ] **勘定科目の標準一覧**: 本システムの「勘定科目候補」に使う科目一覧の確定
- [ ] **税区分**: 課税/非課税/不課税/軽減税率の判定ルール(特に材料仕入と店販商品)
- [ ] **固定資産判定**: 10万円/20万円/30万円の基準と少額減価償却資産特例の適用方針
- [ ] **消耗品判定**: 消耗品費と工具器具備品の線引き
- [ ] **修繕費と資本的支出**: 店舗改装・設備修理の区分基準

## インボイス・証憑

- [ ] **インボイス対応**: 適格請求書の確認手順、免税事業者(業務委託美容師等)との取引の経過措置
- [ ] **保存年限**: 領収書・請求書・帳簿の保存年限と保存方法
- [ ] **電子帳簿保存法対応**: スキャナ保存・電子取引データ保存の要件を本システムの運用(Drive保存)が満たすか

## 支払・報酬関係

- [ ] **個人立替**: スタッフ・代表の立替経費の精算ルールと証憑要件
- [ ] **業務委託報酬**: 業務委託美容師への報酬の源泉徴収要否・消費税・支払調書
- [ ] **給与関連**: 給与・賞与・現物給与の計上タイミング
- [ ] **役員関連支出**: 役員報酬・役員貸付・役員との取引の注意点
- [ ] **税理士・社労士報酬**: 源泉徴収の要否と納付手続き

## 売上計上

- [ ] **Square売上の計上方法**: 総額計上か手数料控除後か。計上日は施術日か入金日か
- [ ] **ホットペッパーポイント**: ポイント利用分・負担分の処理
- [ ] **楽天ポイント**: 同上
- [ ] **クレジットカード利用日と計上日**: カード経費の計上タイミング(利用日基準の可否)
- [ ] **返金・取消処理**: 施術のやり直し・返金時の売上取消の処理

## 経費科目の個別確認

- [ ] **福利厚生費**: スタッフまかない・慶弔・親睦会の範囲
- [ ] **交際費**: 損金算入限度と会議費との区分(1人あたり基準)
- [ ] **会議費**: 対象範囲
- [ ] **広告宣伝費**: ホットペッパー掲載料・モデル撮影費等の扱い
- [ ] **研修費**: 講習会・セミナー・コンテスト参加費の扱い

## 決算・その他

- [ ] **未払金**: 月末未払の計上ルール(毎月か決算時のみか)
- [ ] **前払費用**: 年払い保険料・年間契約広告費の期間配分
- [ ] **リース**: リース契約の会計処理(賃貸借処理の可否)
- [ ] **借入金**: 返済・利息の処理と資料共有方法
- [ ] **税金支払い**: 法人税・消費税・源泉所得税・住民税特別徴収の納付スケジュール管理の分担

## 運用の確認

- [ ] 月次資料の共有方法・期限(Drive `09_税理士共有` フォルダの運用でよいか)
- [ ] 税理士に本スプレッドシートの閲覧権限を付与するか(付与する場合の範囲)
- [ ] 「税理士確認待ち」ステータスの連絡方法(メール通知でよいか)
