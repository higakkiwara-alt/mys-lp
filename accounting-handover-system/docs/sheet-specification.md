# シート仕様書

全シートの構成・列・自動処理の仕様。列定義の正本はソースコード `src/constants.ts` の `SHEETS` です(ここを変更して「シート構成を修復」を実行すると列が追加されます。**既存列の削除・並べ替えは行いません**)。

## 共通仕様

- 1行目: ヘッダー(固定・色付き・フィルター付き)。ヘッダーのメモに【必須】【自動入力】と説明を表示
- 必須入力列: 薄い黄色背景/自動入力列: 薄い灰色背景(手入力不要)
- 日付列 `yyyy-mm-dd`、日時列 `yyyy-mm-dd hh:mm:ss`、金額列 `¥#,##0`
- プルダウン: `13_設定・選択肢マスター`(カテゴリ別リスト)または各マスターシート(範囲参照)
- 管理ID: 先頭列。空欄で行に内容を入れると自動採番(LockServiceで排他)

## 01_経理ダッシュボード

数式(COUNTIFS/SUMPRODUCT/QUERY)による自動集計。スクリプトはレイアウト構築(「数式を再設定」)と最終更新日時のみ担当。

- サマリー: 今月の登録書類数/処理完了件数/未処理件数/期限超過/代表・税理士・社労士確認待ち/原本未保存/金額未入力/会計ソフト未入力/月次締め進捗率/データ不整合件数
- 一覧(QUERY・上位20件): 直近7日以内の期限/緊急案件/支払期限3日以内の請求書/契約更新・解約通知期限
- 内訳(QUERY group by): 店舗別未処理/書類種別別件数/担当者別未処理
- 回答済み・ルール化待ちの質問一覧

## 02_書類受付台帳(42列)

管理ID/受付日/対象年月/書類発行日/支払日/支払期限/対応期限/法人・事業区分/対象店舗/部門/書類種別/書類名・内容/発行元・取引先/宛名/金額/消費税額/支払方法/支払元口座・カード/勘定科目候補/税区分候補/税理士確認必要/インボイス登録番号/適格請求書確認/経費計上月/原本形式/原本保管場所/Google Driveリンク/Gmailリンク/関連URL/受領者/処理担当者/確認者/現在のステータス/次の対応/確認先/重要度/備考/登録日時/最終更新日時/完了日/データ不備フラグ/不備内容

自動処理: ID採番、受付日・登録日時(空欄時)、最終更新日時(常時)、ステータス「処理済み」→完了日(空欄時のみ。戻しても消さない)。
条件付き書式: 期限超過(赤)、緊急(橙)。

## 03_レシート・領収書管理(30列)

管理ID/利用日/登録日/法人・事業区分/対象店舗/利用者/購入先/内容/利用目的/金額/支払方法/使用カード・口座/勘定科目候補/税区分候補/税理士確認必要/インボイス有無/インボイス登録番号/原本・画像リンク/原本保存状況/会計ソフト入力状況/入力日/入力担当者/確認状況/不備内容/重複判定キー/重複候補/ステータス/登録日時/更新日時/備考

自動処理: 重複判定キー=`利用日|購入先|金額|利用者`(onEditで更新)、重複候補=同キーが2行以上でTRUE(条件付き書式で赤)、「入力済み」→入力日。

## 04_請求書・支払管理(27列)

管理ID/請求書受領日/請求日/支払期限/支払予定日/支払完了日/法人・事業区分/対象店舗/取引先/請求内容/請求金額/消費税額/支払方法/支払口座/振込手数料負担/稟議・承認状況/代表承認/請求書リンク/支払証明リンク/会計ソフト入力状況/支払状況/担当者/重要度/税理士確認必要/登録日時/更新日時/備考

自動処理: 「支払済み」→支払完了日。
条件付き書式: 期限超過未払い(赤)/期限3日以内未払い(橙)/代表未承認で支払予定日接近(橙)/支払済みで完了日・証明リンクなし(橙)。

## 05_契約書・重要書類管理(22列)

管理ID/書類種別/契約・書類名/法人・事業区分/対象店舗/相手先/契約開始日/契約終了日/自動更新有無/解約通知期限/更新確認日/担当者/保管場所/Driveリンク/原本保管有無/重要事項/更新・解約時の対応/ステータス/重要度/登録日時/更新日時/備考

条件付き書式: 契約終了日・解約通知期限・更新確認日が超過(赤)/30日以内(橙)。

## 06_書類処理ルール(23列)

ルールID/書類カテゴリ/書類の具体例/受け取った直後にすること/スプレッドシート登録先/必須入力項目/原本の保存方法/Drive保存フォルダ/ファイル名ルール/誰に報告するか/誰の承認が必要か/税理士への共有有無/社労士への共有有無/会計ソフト入力有無/処理期限/処理完了の条件/判断できない場合の対応/税理士確認必要/注意点/関連マニュアルURL/最終更新日/更新者/有効・無効

初期データ35カテゴリ(レシート〜その他判断不明書類)を「初期案」として収録。会社固有の項目は税理士確認必要フラグ付き。

## 07_確認・質問管理(21列)

質問ID/登録日/関連管理ID/法人・事業区分/対象店舗/質問内容/現在分かっている事実/不明点/確認先/重要度/回答期限/回答内容/回答者/回答日/今後の処理方法/ルール化の要否/書類処理ルールへの反映状況/ステータス/登録日時/更新日時/備考

自動処理: 回答内容の入力→回答日。回答済み+要ルール化+未反映はダッシュボード表示&不整合検出。

## 08_月次締めチェックリスト(15列)

チェックID/対象年月/チェック項目/対象店舗/担当者/期限/実施状況/完了日/確認者/証拠リンク/問題・不足事項/次の対応/登録日時/更新日時/備考

生成: 20項目(店舗単位8項目×稼働店舗+全社単位12項目)。同じ 年月+店舗+項目 は重複生成しない。期限は翌月5/7/10/15/20/25日(項目別)。毎月1日に自動生成+メニューから任意の年月を手動生成可能。

## 09_定期支払・固定費管理(21列)

管理ID/法人・事業区分/対象店舗/費目/支払先/契約内容/支払頻度/通常金額/支払日/支払方法/使用口座・カード/契約書リンク/請求書の取得方法/担当者/解約方法/解約期限/自動更新/ステータス/登録日時/更新日時/備考

## 10〜12 マスター

- **10_取引先マスター(16列)**: 取引先ID/取引先名/取引内容/担当者名/電話番号/メールアドレス/法人番号/インボイス登録番号/通常の支払方法/通常の勘定科目候補/税区分候補/対象店舗/契約書リンク/請求書取得方法/有効・無効/備考
- **11_店舗・事業マスター(13列)**: 事業ID/法人・個人事業区分/法人・事業名/店舗名/店舗コード/所在地/管理責任者/使用銀行口座/使用クレジットカード/Square店舗名/会計上の部門名/稼働状況/備考。「稼働中」の店舗のみプルダウン・月次生成の対象
- **12_担当者マスター(10列)**: 担当者ID/氏名/役割/所属店舗/メールアドレス/対応可能業務/承認権限/通知対象/稼働状況/備考。「通知対象」チェックで通知メール宛先に追加

## 13_設定・選択肢マスター(4列)

カテゴリ/設定値/表示順/有効。ステータス(15値)・重要度・法人事業区分・原本形式・支払方法・確認先・会計ソフト入力状況・支払状況・書類種別ほか24カテゴリを収録。変更後は「入力規則を再設定」を実行。

## 14〜16 ログ・不整合

- **14_変更履歴(11列)**: 変更ID/変更日時/シート名/管理ID/行番号/変更した担当者/変更した列/変更前/変更後/操作種別/備考。対象列: 金額・消費税額・支払日・支払予定日・支払完了日・支払状況・ステータス・各リンク・担当者・確認者・回答内容・会計ソフト入力状況・原本保存状況。一括貼り付けは200件まで記録し超過は件数を記録
- **15_システムログ(9列)**: ログ日時/レベル(INFO・WARN・ERROR)/処理名/メッセージ/対象シート/対象管理ID/実行ユーザー/エラー詳細/備考。5000行超で古い行を自動削除
- **16_エラー・不整合一覧(10列)**: 検出日時/不整合種別/重要度/対象シート/管理ID/問題内容/修正方法/担当者/対応状況/完了日。検出種別15種(期限超過・支払漏れ・原本未保存・ID重複・マスター不一致・ルール未反映など)。同一不整合(種別+シート+ID)は重複登録せず、解消時は自動で「解消済み」+完了日

## 17〜21 外部連携シート(Phase 2)

- **17_売上データ取込(10列)**: 取込キー/日付/店舗/売上金額/手数料/純入金額/取引件数/ソース/取込日時/備考。Square API から日次で自動取込(取込キー=日付|店舗|ソース で冪等・上書き更新)
- **18_明細取込(13列)**: 取込キー/種別/口座・カード名/日付/摘要/入金額/出金額/残高/突合状況/関連管理ID/ソースファイル/取込日時/備考。Drive「04_銀行・カード明細/取込待ち」のCSVから取込(内容ハッシュで重複防止)
- **19_店舗別月次集計(11列)**: 集計キー/対象年月/店舗/売上/経費(レシート)/経費(請求書)/粗利/売上取引件数/経費件数/生成日時/備考。月次レポートジョブが対象年月分を洗い替え
- **20_ファイル分類提案(16列)**: 提案ID(FCP-0001)/ファイル名/ファイルURL/推定書類種別/提案フォルダ/提案ファイル名/推定日付/推定金額/推定取引先/OCR抜粋/関連管理ID/ステータス(提案中→承認→実行済み)/実行日時/エラー/登録日時/備考。**承認された行のみ**メニューから移動・改名を実行
- **21_Gmail取込(11列)**: メッセージID/受信日時/差出人/件名/添付ファイル名/Driveリンク/Gmailリンク/台帳管理ID/取込状況/取込日時/備考。処理済みメールの記録(二重取込防止)

詳細な設定・運用は `integration-guide.md` 参照。

## 90_フォーム受付(中間)

フォーム回答の中間シート。回答は onFormSubmit で 02_書類受付台帳 へ整形して自動登録される(回答原本はフォームの回答シートに残る)。
