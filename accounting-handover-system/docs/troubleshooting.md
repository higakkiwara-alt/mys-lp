# トラブルシューティング

問題が起きたら、まず `15_システムログ` シートの最新のERROR行を確認してください。多くのエラーは原因がそこに日本語で記録されています。

## セットアップ・デプロイ

### メニュー「OTK経理管理」が表示されない

- ページをリロードする(メニューは開いた時に作られます)
- それでも出ない場合: `npm run build && npm run clasp:push` を再実行 → リロード
- Apps Script エディタで `onOpen` を直接実行してエラーが出ないか確認

### `clasp push` で 403 / "User has not enabled the Apps Script API"

https://script.google.com/home/usersettings で「Google Apps Script API」をオンにして数分待ってから再実行。

### `clasp push` で "Invalid credentials"

`npm run clasp:login` で再ログイン。

### `.clasp.json が見つかりません` エラー

`cp .clasp.json.example .clasp.json` を実行し、`scriptId` を設定(README手順7)。

### 「承認が必要です」ダイアログが何度も出る

「詳細」→「(プロジェクト名)に移動」→「許可」まで進めてください。組織のGoogle Workspaceで管理者がサードパーティアプリを制限している場合は管理者に確認。

## 実行時

### 「ロックを取得できませんでした」

他の処理(別ユーザーの編集、トリガー)が実行中です。1分待って再実行。頻発する場合は15_システムログで長時間処理が無いか確認。

### 「シート「◯◯」に列「◯◯」がありません」

誰かが列を削除した可能性 → メニュー「シート構成を修復」を実行(不足列が右端に追加されます。データは消えません)。

### 管理IDが自動で入らない

- インストーラブルトリガーが未作成 → 「初期セットアップ」を再実行(トリガーが再登録されます)
- Apps Script エディタ左の「トリガー」に `handleEditInstallable` があるか確認

### 完了日・支払完了日が入らない

ステータス値が `13_設定・選択肢マスター` の値と完全一致しているか確認(「処理済み 」のような末尾スペースはNG。プルダウンから選ぶこと)。

### ダッシュボードが「該当なし」「#ERROR!」になる

- メニュー「数式を再設定」を実行(列位置を再解決して数式を作り直します)
- スプレッドシートの言語設定が日本語以外の場合、`ファイル → 設定 → ロケール` を「日本」にする

### プルダウンに新しい店舗・選択肢が出ない

- 店舗・担当者・取引先: マスターの行を追加すれば即反映(範囲参照)。反映されない場合は「入力規則を再設定」
- ステータス等(13_設定・選択肢マスター): 変更後に**必ず**「入力規則を再設定」を実行

### 通知メールが届かない

1. Script Properties の `NOTIFICATION_ENABLED` が `true` か
2. `CEO_EMAIL` / `ACCOUNTING_EMAIL` が設定されているか(「システム設定を確認」で表示)
3. 「通知テスト」を実行 → 15_システムログを確認
4. 同じ内容は約1日1回しか送られません(重複抑止)。テストを繰り返すと「送信されませんでした」となるのは正常
5. Gmailの1日あたり送信上限(無料アカウント約100通)超過の可能性 → 翌日再試行

### フォーム回答が台帳に取り込まれない

- トリガー `handleFormSubmit` の存在を確認(「初期セットアップ」で再作成)
- フォームの回答先が本スプレッドシートになっているか(フォーム編集画面 → 回答 → スプレッドシートアイコン)

### Driveフォルダ作成で権限エラー

15_システムログに「Drive権限不足」が出る場合、承認時にDrive権限を許可していません。Apps Script エディタで任意の関数を実行し直し、承認をやり直してください。

### 一括貼り付け後、一部の行にIDが入らない

onEditは1回の編集で最大200行まで処理します。201行以上を貼り付けた場合は、該当行の任意のセルを再編集するか、行を分けて貼り付けてください。

## データ

### 間違えて行・値を消した

1. `14_変更履歴` で変更前の値を確認して手で戻す
2. ファイル → 版の履歴 → 変更履歴を表示 → 対象時点に戻す(**他の人の編集も戻るため代表へ確認してから**)

### 不整合一覧に同じ問題が2行ある

古い方の対応状況を「対象外」にしてください(通常は 種別+シート+管理ID で重複登録されません。管理IDが後から変わった場合に起こりえます)。

### サンプルデータを消したい

メニュー「サンプルデータを削除」。備考が「【サンプル】」で始まる行だけが削除されます。マスターの仮データを書き換えて使っている場合は、備考の【サンプル】表記を先に消しておくこと(消さないと削除対象になります)。

## それでも解決しないとき

1. `15_システムログ` のERROR行のスクリーンショットを撮る
2. `07_確認・質問管理` に「システム不具合」として起票し、代表(またはシステム管理者)へ連絡
3. 復旧までは手入力運用(IDは仕様書のID体系に従って手動採番)で業務を止めない
