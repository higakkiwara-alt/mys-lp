# 経理引き継ぎチェックリスト

経理担当者の交代時に、前任者と後任者がこのリストを一緒に埋めてください。
**注意: パスワードそのものをこの文書やスプレッドシートに記録しないでください。**「どこに保管されているか(例: 会社のパスワード管理ツール名、金庫)」だけを記録します。

## 1. アカウント・サービスの棚卸し

- [ ] **使用銀行口座一覧**: 銀行名/支店/口座種別/名義/用途(店舗別か全社か)/通帳・カードの保管場所
- [ ] **クレジットカード一覧**: カード会社/名義/引落口座/主な用途/明細の確認方法(Web/郵送)
- [ ] **Squareアカウント**: ログインメールアドレス/店舗設定/入金サイクル/明細のダウンロード方法
- [ ] **ホットペッパービューティー**: 管理画面のURL/契約プラン/請求サイクル/担当営業の連絡先
- [ ] **楽天ビューティー**: 管理画面のURL/契約内容/明細の取得方法
- [ ] **会計ソフト**: 製品名/ログイン方法/入力ルール(誰が・いつ・どこまで)
- [ ] **ログイン情報の管理場所**: すべてのID・パスワードがどこで管理されているか(ツール名・場所のみ)

## 2. 専門家・外部連絡先

- [ ] **税理士情報**: 事務所名/担当者/連絡方法/顧問契約の範囲/月次資料の共有方法・期限
- [ ] **社労士情報**: 事務所名/担当者/連絡方法/委託範囲(給与計算・手続き)
- [ ] その他(行政書士・銀行担当者・保険代理店)

## 3. 業務の現在地(シートで確認)

- [ ] **定期支払**: `09_定期支払・固定費管理` が実態と一致しているか突合
- [ ] **未処理書類**: `01_ダッシュボード` の未処理件数と `02_書類受付台帳` の中身を後任者と一緒に確認
- [ ] **未払い請求書**: `04_請求書・支払管理` で「未払い」「支払予定」を全件確認
- [ ] **契約更新予定**: `05_契約書・重要書類管理` で解約通知期限が6ヶ月以内のものを確認
- [ ] **月次締め状況**: `08_月次締めチェックリスト` の当月・前月の残項目
- [ ] **未回答の質問**: `07_確認・質問管理` の未回答分の引き継ぎ

## 4. 保管場所

- [ ] **Drive保管場所**: 「経理管理」フォルダのURLと構成(`drive-folder-structure.md`)
- [ ] **原本保管場所**: 紙の原本の物理的な場所(店舗トレー/事務所キャビネット/過年度の箱)
- [ ] スプレッドシート本体のURLと編集権限の付与

## 5. 暗黙知の言語化(最重要)

- [ ] **担当者しか知らない業務**を書き出す(例: 「◯◯商事は月末締め翌20日払いだが、請求書が遅れて来るので電話で確認している」)
  - 書き出した内容は `06_書類処理ルール` の該当カテゴリの「注意点」列へ転記する
- [ ] 毎年発生する業務(年末調整・償却資産申告・労働保険年度更新など)の時期と段取り
- [ ] 取引先ごとの癖・注意点 → `10_取引先マスター` の備考へ

## 6. 引き継ぎ研修

- [ ] 1日目: このシステムの構成説明(README + 運用マニュアル)
- [ ] 1週目: 前任者が処理し、後任者が横で見る
- [ ] 2週目: 後任者が処理し、前任者が確認する
- [ ] 3-4週目: 後任者のみで処理し、質問は `07_確認・質問管理` 経由で行う

## 7. 引き継ぎ完了判定

以下がすべて Yes になったら引き継ぎ完了とする:

- [ ] 後任者が1人で「書類受付→処理→会計入力→原本保存」を完了できた
- [ ] 後任者が1人で月次締めチェックリストを完了できた
- [ ] ダッシュボードの期限超過が0件の状態を1ヶ月維持できた
- [ ] 未回答の質問がすべて後任者に引き継がれた
- [ ] 前任者のアカウント権限の棚卸し(不要な共有の削除)が完了した
- [ ] 代表が完了を承認した(日付: 承認者: )
