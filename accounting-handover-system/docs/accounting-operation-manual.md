# 経理運用マニュアル(担当者別)

このマニュアルは「誰が・いつ・何をするか」を具体的な行動で書いています。
迷ったら `06_書類処理ルール` シートを見る → それでも分からなければ `07_確認・質問管理` に登録する、が基本です。

---

## 1. 書類を受け取ったスタッフ

**あなたの仕事は「その日のうちに登録して、原本を保管box(または店舗の書類トレー)に入れる」ことだけです。**

1. レシート・書類を受け取ったら、スマホで写真を撮る
2. 「OTK経理 書類・レシート受付フォーム」を開く(店舗のブックマーク/QRコード)
3. 全項目を入力して送信(金額が読めない・分からない項目は空欄でOK)
4. 写真をDriveの `経理管理/00_未分類・新規受付` へアップロードし、URLをフォームに貼る
5. 原本(紙)は捨てずに店舗の「経理トレー」へ入れる

**やってはいけないこと**: 原本を捨てる/登録せずに放置する/自分で経費かどうか判断して除外する

## 2. 店舗責任者

**毎週やること**

1. 店舗の経理トレーの書類が全部フォーム登録されているか確認
2. `02_書類受付台帳` で自店舗の行を確認(フィルターで対象店舗を絞る)
3. 不備(金額なし・写真なし)があればスタッフに確認して修正
4. 月末: 店舗のレシート・売上資料を経理担当者へ引き渡す

**権限**: 自店舗の書類の確認・不備修正・担当者割り当てまで。**支払の承認はできません**(代表へ)。

## 3. 経理担当者

**毎日やること(朝、15分)**

1. `01_経理ダッシュボード` を開く
2. 「期限超過」「支払期限3日以内」が0件でなければ最優先で対応
3. `02_書類受付台帳` の「未処理」を上から処理:
   - `06_書類処理ルール` で該当カテゴリの行を見る
   - 書類種別・店舗・金額・期限・勘定科目候補を入力
   - 原本をルール記載のDriveフォルダへ保存し、リンクを貼る
   - ステータスを進める(内容確認中→担当者対応中→…→処理済み)
4. 判断できないものは `07_確認・質問管理` へ登録(確認先と回答期限を必ず入れる)

**請求書が来たら**

1. `04_請求書・支払管理` へ登録(受領日・支払期限は必須)
2. 高額(運用基準は代表と決めて06へ記載)は「代表承認」を「承認待ち」にして代表へ連絡
3. 支払ったら「支払済み」へ変更(支払完了日は自動)+振込明細を `03_支払証明` へ保存しリンクを貼る
4. 会計ソフトへ入力したら「入力済み」へ(入力日は自動)

**毎月やること**

1. 毎月1日に自動生成される `08_月次締めチェックリスト` を上から実施
2. 各項目を「完了」にする(証拠リンク欄に資料リンクを貼る)
3. 15日までに会計ソフト入力と税理士共有資料(`09_税理士共有` フォルダ)を揃える
4. 20日までに代表へ月次報告 → 「月次締め完了」を完了にする

**質問の回答が来たら**

1. `07_確認・質問管理` に回答内容・回答者を記録
2. 今後も起きることなら「ルール化の要否=要」にして `06_書類処理ルール` を更新
3. 更新したら「反映状況=反映済み」へ

## 4. 代表

**見る場所は `01_経理ダッシュボード` だけで足ります(1日1回・1分)。**

- 「代表確認待ち件数」が1以上 → `02_書類受付台帳` でステータス「代表確認待ち」をフィルターして判断
- 「期限超過」「緊急案件」が1以上 → 経理担当者へ確認
- 「支払期限3日以内の請求書」の一覧 → 承認が必要なものは `04` の「代表承認」を「承認済み」へ
- 月次締め進捗率 → 20日を過ぎて100%でなければ経理担当者へ確認
- 通知メール(毎朝)でも同じ内容が届きます

**代表しかできないこと**: 支払の最終承認/新しい店舗・担当者の追加判断/経理ルールの最終決定

## 5. 税理士共有担当(経理担当者が兼務可)

1. ステータス「税理士確認待ち」の行を週1回まとめる
2. 該当書類を Drive `09_税理士共有` フォルダへコピー(移動ではなくコピー)
3. 税理士からの回答は `07_確認・質問管理` に記録し、必要なら `06_書類処理ルール` へ反映
4. 月次: 会計ソフト入力完了後、月次資料一式を `09_税理士共有` へ格納して税理士へ連絡

---

## 共通ルール(全員)

- **原本は捨てない**(保存年限は税理士確認事項。確認まで全保管)
- **台帳に載っていない書類は存在しないのと同じ**。必ず登録する
- 勘定科目・税区分はすべて「候補」。最終判断は税理士
- パスワードをシートに書かない(保管場所の名前だけ)
- ステータスの意味が分からなくなったら `13_設定・選択肢マスター` を見る
