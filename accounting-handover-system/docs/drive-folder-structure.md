# Google Drive フォルダ構成

メニュー「Driveフォルダを作成」で以下が自動作成されます。既存フォルダは名前で再利用され、**重複作成・ファイルの移動・削除は行いません**。ルートフォルダ名は Script Properties `DRIVE_ROOT_FOLDER_NAME`(既定: 経理管理)で変更できます。

```
経理管理/
├── 00_未分類・新規受付/          ← 迷ったらここ。フォーム添付の一次置き場
├── 01_レシート・領収書/
│   └── YYYY/
│       └── YYYY-MM/
│           └── 店舗名/           ← 稼働店舗ごとに当月分を自動作成
├── 02_請求書/
│   └── YYYY/
│       └── YYYY-MM/
├── 03_支払証明/                  ← 振込明細・払込受領書
├── 04_銀行・カード明細/
├── 05_売上資料/
│   ├── Square/
│   ├── ホットペッパー/
│   └── 楽天ビューティー/
├── 06_契約書/
│   ├── 店舗賃貸借/
│   ├── 業務委託/
│   ├── 雇用/
│   ├── 広告/
│   ├── システム/
│   └── その他/
├── 07_税務・行政/
│   ├── 税務署/
│   ├── 都税事務所/
│   ├── 市役所/
│   ├── 年金事務所/
│   ├── ハローワーク/
│   ├── 労働基準監督署/
│   └── 保健所/
├── 08_給与・報酬/
├── 09_税理士共有/                ← 税理士に共有するものはここへ「コピー」
├── 10_月次締め/                  ← 月次資料一式(YYYY-MM フォルダを手動作成)
└── 99_保管・過年度/              ← 年度終了後のアーカイブとバックアップ
```

## 運用ルール

1. **どこに保存するか迷ったら `00_未分類・新規受付`**。週次で経理担当者が仕分ける
2. 保存先はカテゴリごとに `06_書類処理ルール` の「Drive保存フォルダ」列に記載されている
3. 保存したらスプレッドシートの該当行に**リンクを必ず貼る**(リンクなしは不整合検出される)
4. 税理士共有は**移動ではなくコピー**(原本の場所を変えない)
5. 月が変わったら「Driveフォルダを作成」を再実行すると当月フォルダが追加される(毎月1日の実行を推奨)
6. 削除は原則禁止。誤アップロードのみ削除可(原本書類ファイルは削除しない)

## 提案ファイル名ルール

```
YYYYMMDD_法人または店舗名_取引先_書類種別_金額_管理ID.pdf
例: 20260710_OTK_COMPANY_〇〇商事_請求書_55000_ACC-202607-0001.pdf
```

- 使用禁止文字(\/:*?"<>| など)は自動除去、空白は `_`、金額のカンマは除去、全体120文字以内
- 既存ファイルの**自動改名は行いません**。新規保存時にこの形式を使ってください(生成ロジック: `src/utils/helpers.ts` の `buildFileName`)
- ファイル名に個人情報(顧客名・スタッフ個人名等)を必要以上に含めないこと

## 権限

- `経理管理` 直下: 代表・経理担当者のみ編集可
- `09_税理士共有`: 税理士に「閲覧者(またはコメント可)」で共有
- 店舗スタッフには `00_未分類・新規受付` のみ「編集者」で共有(アップロード用)
