# BIG BAMBOO 幹部成長制度 ― 評価制度ドキュメント（FINAL）

- 対象：幹部・幹部候補（当面は里佳子・吉田）
- 位置づけ：動画「幹部成長制度（里佳子・吉田向け）」の正本ドキュメント
- ステータス：制度の骨格は確定方針。**報酬の金額・料率、個人別の評価値は「仮案・要最終承認」**

---

## 1. この制度の目的

評価制度は「人を落とすため」「序列を作るため」のものではない。目的は次の3つだけ。

1. **現在地を知る** ― 8軸×5段階で、いまの自分の位置が分かる
2. **次に伸ばす能力を決める** ― 次の期間で集中して磨く力を1〜2個選ぶ
3. **次に任せる仕事を決める** ― レベルに応じて、新しい仕事と権限を渡す

査定の道具ではなく、**成長の地図**として運用する。

### 前提となる考え方

- 現状維持は実質的な衰退（物価・人件費・競争は上がり続けている）。ただしゴールは「一生頑張り続ける」ことではなく、**将来頑張り続けなくてもいい状態を今つくること**
- 最大の損失はお金ではなく**時間**（何も変えなければ、技術・売上・指名・マネジメント・育成・仕組み化・人脈・選択肢が積み上がらないまま失われる）
- BIG BAMBOOの考える**自立**＝自分で考え、自分で稼ぐ力を持ちながら、仲間・会社・仕組みを使い、自分の時間・収入・働き方・人生の選択肢を増やせる状態
- 一人で頑張るより、**チームで大きな成果を作る**

### 会社の軸

| 項目 | 内容 |
|---|---|
| Purpose | 美容師のための美容室を100年残す。 |
| Philosophy | 人が育ち、会社が育ち、文化が残る。 |
| Vision | 美容師が安心して挑戦し、自立し、人生を豊かにできる社会をつくる。 |
| Mission（仮案・要最終承認） | 美容師が、一人で背負わなくても自立できる未来をつくる。 |

---

## 2. 幹部の定義

> 幹部とは、**自分が成果を出す人**から、**人と仕組みを通してチームの成果を作る人**へ進んだ人。

- 売上No.1だから幹部、ではない
- 技術が一番上手いから幹部、でもない
- 最重要は「**自分がいなくても成果が出るチーム・店舗・仕組みを作ること**」

### マネージャーの成果の考え方

| | A | B（幹部として評価するのはこちら） |
|---|---|---|
| 自分の売上 | 250万円 | 100万円 |
| 店舗全体 | 250万円（自分のみ） | 600万円（チーム500万円） |
| チームへの影響 | 周囲は育たない／休むと数字が落ちる | スタッフが育つ／自分がいなくても数字が出る |

「自分がどれだけ働いたか」から、「**自分を通してどれだけチームの成果を増やしたか**」へ。

## 3. 評価の8軸

| # | 軸 | 中身 |
|---|---|---|
| 1 | Professional | 言葉遣い／態度／礼節／時間／約束 |
| 2 | Self Management | 自己管理／感情管理／報連相／安定性 |
| 3 | Execution | 任された仕事を最後まで完了／抜け漏れ防止／再現性 |
| 4 | Problem Solving | 問題発見／原因整理／提案／改善 |
| 5 | Teamwork | 周囲を見る／助ける／協調／チーム成果を考える |
| 6 | Leadership | 方向を示す／人を動かす／まとめる／判断する |
| 7 | Development | 人を育てる／教える／仕事を渡す／後任を作る |
| 8 | Management | 売上／利益／人材／店舗／数字／会社視点 |

構造：**土台（1〜4）→ チームと経営（5〜8）**へ積み上がる。

## 4. 5段階レベル（全軸共通）

| レベル | 名称 | 状態 |
|---|---|---|
| LEVEL 1 | 教えてもらう | まだ一人では完結できない |
| LEVEL 2 | 自分でできる | 自分の仕事として完了できる |
| LEVEL 3 | 安定してできる | 状況が変わっても安定して再現できる |
| LEVEL 4 | 人に教えられる | 他のスタッフにも再現させられる |
| LEVEL 5 | 仕組みにできる | 自分がいなくても回る状態を作れる |

**LEVEL 4からが「幹部の入口」**。自分ができるかではなく、人に再現させられるか。

---

## 5. 報酬との連動

連動の順番：**能力 → 任せられる仕事 → 責任範囲 → 成果 → 報酬**

方針：「責任だけ増えて給料が変わらない管理職」にはしない。

### 設計の考え方（仮案・要最終承認）

例：スタイリストとして月50万円程度稼いでいる人を管理側へ移す場合、管理業務のために入客を減らした結果、収入が大きく下がる設計にはしない。

```
これまでの収入を一定程度担保
＋ 管理手当
＋ 店舗業績に応じた成果報酬
```

- **金額・料率は未確定**。確定制度ではないため、社内向け資料・面談では断定しない
- 確定した約束は方向性のみ：**能力・責任・店舗成果に応じて報酬が上がる仕組みを作る**

---

## 6. レッドフラッグ（幹部として避ける行動）

- 陰で不満だけ言う
- 人によって態度を変える
- 言葉遣い・礼節を軽視する
- 感情で判断する
- 報告しない
- 部下のせいにする
- 数字を見ない
- 問題だけ持ってきて提案しない
- 自分一人で抱え込む
- 属人化する
- 同じミスを繰り返す
- 決め事を自己判断で変える

特に：**「自分にしかできない仕事」を増やすことは幹部として高評価ではない**。誰でもできる形にして人に渡せる人を評価する。

総合：**約2.7 / 5**（大竹の見立て。面談で本人の実感とすり合わせて確定する）

### 軸別の仮置き（参考値・仮案）

| 軸 | 仮評価 | メモ |
|---|---|---|
| Professional | 2.0 | 言葉遣い・態度・自己管理が次の伸ばしどころ |
| Self Management | 2.5 | 安定性・整理する力を強化 |
| Execution | 3.0 | 現場業務は安定して回せている |
| Problem Solving | 2.5 | 課題の整理→提案までを習慣化 |
| Teamwork | 3.5 | スタッフとの関係性・コミュニケーションは強み |
| Leadership | 2.5 | 引っ張る・まとめる・決める場面を増やす |
| Development | 2.0 | 後輩育成・仕事を渡す力が最重要テーマ |
| Management | 3.5 | すでに店舗管理業務を実際に担っている |

### 強み

- 現場経験がある（お店のリアルを知っている）
- 店舗管理業務をすでに実際に担っている
- スタッフと関係性を作れている／コミュニケーションが取れる

### 次の成長ポイント

1. プロフェッショナルの土台（言葉遣い・態度・自己管理）
2. 仕事を整理してまとめる力
3. 自分目線ではなく会社目線
4. 後輩を育てて、仕事を人に渡す力

### 次のテーマ

> 「自分が店舗を回す」から「**自分がいなくても回る店舗を作る**」へ

**重要評価項目：吉田を育てられるか。** 仕事を渡せた分だけ、里佳子はさらに上位の仕事へ進む。

## 8. 吉田の現在地と1年ロードマップ

### 現時点で評価していること

- 言葉遣い・礼節／大竹・周囲への接し方
- 真面目さ・素直さ／仕事への姿勢
- マネジメント適性（8軸の「土台」がすでにある）

→ 現能力より、**将来の管理・マネジメント候補として期待**。里佳子との比較・競争はさせない。

### 12か月ロードマップ

| 期間 | テーマ | 内容 |
|---|---|---|
| 0〜3か月 | 店舗業務の基本 | 在庫管理／レジ締め／発注／日次報告／基本的な店舗業務 |
| 3〜6か月 | 店舗を支える側へ | シフト補助／クレーム一次対応／スタッフフォロー／店舗課題の報告／改善提案 |
| 6〜12か月 | 管理業務を並行習得 | 里佳子の管理業務を並行して習得（店舗管理／スタッフ管理／日次・週次・月次報告／問題対応／店舗改善） |

**1年後の目標：里佳子がいない日でも、店舗運営を一定レベルで完結できる。**

売上の目安は 100万 → 120万 → 150万円（参考値）。ただし**幹部候補としての最重要評価は売上だけではなく管理能力**。

## 9. 二人の関係（競争ではなく、渡して両方が上がる）

```
里佳子：いま持っている仕事を吉田に教える
　→ 吉田：学んで、自分でできる状態になる
　→ 吉田：店舗管理業務を引き継ぐ
　→ 里佳子：さらに上位の仕事へ進む
```

- 役職は固定ではない。能力・希望・成果によって将来の役割は変わる
- 「仕事を渡すこと＝上に進む階段」

---

## 10. 店舗運営の理想状態

| 店舗側で完結 | 本部側が支える |
|---|---|
| スタッフ管理／教育／店舗売上／予約管理／在庫／発注／シフト／クレーム一次対応／店舗改善／日次管理／週次報告／月次報告 | 経理／財務／税務／AI・システム／経営戦略／バックオフィス／全社マーケティング支援 |

大竹は現場の細かい判断に毎日入るのではなく、**週次・月次報告を見て重要判断をする**。これができれば**店舗展開が可能になる**。

---

## 11. 運用ルール（仮案・要最終承認）

- 評価サイクル：四半期ごとに面談（自己評価＋大竹評価→すり合わせ）
- 各面談で決めること：①現在地の確認 ②次の期間で伸ばす軸1〜2個 ③新しく任せる仕事
- 評価値は本人と共有し、公開の序列付けには使わない
- 制度・数値は運用しながら改訂する（本ドキュメントを正本として更新）
