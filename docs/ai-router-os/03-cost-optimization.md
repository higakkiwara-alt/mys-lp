# 03. コスト最適化設計(要件③)

## 1. モデル使用ルール(コスト規律)

| ランク | モデル | 価格(入/出 per 1Mトークン) | 使用条件 |
|---|---|---|---|
| S | **Fable 5** `claude-fable-5` | $10 / $50 | **本当に必要な時だけ**: 経営判断・戦略設計・高度な壁打ち(complexity≥4 かつ intent=think)。Router の許可制 |
| A | Opus 4.8 `claude-opus-4-8` | $5 / $25 | Fable 5 の refusal フォールバック先。高度なコードレビュー |
| B | **Sonnet 5** `claude-sonnet-5` | $3 / $15(intro: $2 / $10) | **標準**: 文章生成・分析・各Agentの既定モデル |
| C | Haiku 4.5 `claude-haiku-4-5` | $1 / $5 | 分類・要約・整形・report 生成 |
| — | **Claude Code** | 定額(Maxプラン)/ API従量 | **実装**: コード生成・リファクタ・テスト |

### 強制ルール(コードで担保)

1. Fable 5 は Router 経由でのみ呼べる(直接呼び出し関数を export しない)
2. Fable 5 呼び出しには `reason`(なぜ必要か)を必須引数にし、ログに残す
3. 1日の Fable 5 コスト上限(既定: $10/日)を超えたら Sonnet に自動降格 + Dashboard に警告
4. 大量文章は必ず Sonnet + ストリーミング。Haiku で済む整形を Sonnet でやらない
5. プロンプトキャッシュ必須: Agent システムプロンプトは固定文字列にして `cache_control` を付与(読み取り約0.1倍)

## 2. 推定コスト(1件あたり)

前提: 日本語1文字 ≈ 1〜2トークン。数値は代表的なトークン量からの概算。

| ユースケース | 構成 | 推定トークン(入/出) | 推定コスト |
|---|---|---|---|
| 依頼の分類(全件) | Haiku | 1.5K / 0.3K | **$0.003** |
| SNS投稿1本(例A: think+write+整形) | Sonnet ×3 | 6K / 4K | **$0.08** |
| ブログ記事1本(3,000字) | Sonnet | 4K / 6K | **$0.10** |
| 教材1本(1万字+図解プロンプト) | Sonnet ×4 | 15K / 20K | **$0.35** |
| 経営壁打ち30分相当(往復10回) | **Fable 5** | 80K / 40K | **$2.80** |
| 経営分析レポート(データ+深い思考) | Fable 5 ×1 + Sonnet ×2 | 30K / 15K + α | **$1.20** |
| 画像1枚 | 画像生成API | — | $0.04〜0.17(品質による) |
| 動画1本(30秒) | 動画生成API | — | $1〜5(サービスによる。Phase2で確定) |
| 音声文字起こし10分 | Whisper系 | — | $0.06 |

### 月間シミュレーション(運用イメージ)

| 項目 | 量/月 | 単価 | 小計 |
|---|---|---|---|
| SNS投稿(4媒体×毎日) | 120本 | $0.08 | $9.6 |
| ブログ/SEO記事 | 20本 | $0.10 | $2.0 |
| 教材 | 8本 | $0.35 | $2.8 |
| 経営壁打ち・判断(Fable 5) | 20回 | $2.80 | **$56.0** |
| 画像 | 150枚 | $0.08 | $12.0 |
| 分類・report等(Haiku) | 500件 | $0.003 | $1.5 |

| **合計(動画除く)** | | | **≈ $86/月(約13,000円)** |

→ コストの65%が Fable 5。**「本当に必要な時だけ」ルールが効くほど支配的に効く**。
→ 動画を本格運用すると +$30〜150/月。Phase2 で単価を見てから判断。

## 3. コスト削減テクニック(実装に組み込む)

| 手法 | 効果 | 実装 |
|---|---|---|
| プロンプトキャッシュ | 固定プロンプト部が約1/10 | Agentプロンプトに `cache_control: {type: "ephemeral"}` |
| Batches API | 非急ぎ処理が **半額** | 深夜バッチ(競合分析・リライト等)は `messages.batches` |
| Sonnet intro価格 | 2026-08-31まで $2/$10 | 今のうちに Sonnet 中心の運用を確立 |
| effort 制御 | 出力トークン削減 | 定型タスクは `output_config: {effort: "low"}` |
| 分類の前置き | 高額モデルの誤爆防止 | 全依頼を Haiku で分類してから振り分け |

## 4. コスト表示(要件「推定コストも表示」)

- **実行前**: Router が実行プランと同時に「推定コスト」を返す(上表の単価テーブル × 予定ステップ)
- **実行後**: 各ステップの実トークン(`usage`)× 単価で実コストを RouterStep に記録
- **Dashboard**: 日次/月次コスト、モデル別内訳、Fable 5 上限の消化率を表示(07参照)
- 単価テーブルは `lib/router/pricing.ts` に一元化(価格改定時に1箇所直すだけ)
