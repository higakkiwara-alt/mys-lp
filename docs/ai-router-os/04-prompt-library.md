# 04. プロンプトライブラリ設計(要件④)

用途別に整理・バージョン管理されたプロンプト資産。Obsidian Vault の `Prompt/` 配下に Markdown で保存し、
Router/Agent が実行時に読み込む(= プロンプト自体も Company OS の資産)。

## 1. 保存形式

1プロンプト = 1 Markdown ファイル。frontmatter でメタデータを持つ。

```markdown
---
id: sns-instagram-post
title: Instagram投稿文生成
category: SNS/Instagram
agent: SNS
model: claude-sonnet-5
version: 3
updated: 2026-07-07
tags: [SNS, Instagram, 美容室]
variables: [テーマ, ターゲット, CTA]
---

# 役割
あなたは美容室「Mys立川」のSNS担当。髪質改善専門店としての世界観を守る。

# 指示
{{テーマ}} について、{{ターゲット}} に刺さるInstagram投稿文を作成…

# 制約
- 冒頭1行でスクロールを止める
- ハッシュタグは10個(ビッグ3+ミドル4+ローカル3)
…
```

- `variables` は実行時に Router が依頼文から抽出して差し込む
- 変更は Git 履歴 = バージョン管理。`version` は人間可読用
- Dashboard から「このプロンプトの成功率・使用回数」を参照できるよう `id` を実行ログに記録

## 2. カテゴリ構成(初期セット)

```
Prompt/
├── 経営/          経営判断フレーム, 事業計画レビュー, KPI設計, 意思決定記録テンプレ
├── 採用/          求人原稿, 面接質問設計, スカウト文, 採用基準チェック
├── 教育/          教材構成, 講師台本, 理解度テスト, カリキュラム設計
├── 営業/          提案書, 商談準備, フォローメール, 反論処理, クロージング
├── 美容/          カウンセリング台本, メニュー説明, 口コミ返信, 施術ブログ, MEO投稿
├── SNS/
│   ├── YouTube/   企画, タイトル/サムネ案, 台本, 概要欄
│   ├── Instagram/ フィード投稿, リール台本, ストーリーズ, ハッシュタグ
│   └── TikTok/    ショート台本, トレンド適用, フック集
├── 動画/          構成台本, ナレーション, テロップ, カット指示
├── 売却・M&A/     企業価値整理, 事業計画書, DD準備チェック, ティーザー文書
├── 税務/          税理士への質問整理, 経費判断メモ, 節税論点リスト ※助言は専門家確認前提
├── 法務/          契約書レビュー観点, 利用規約ドラフト, リスクチェック ※同上
└── 共通/          要約, 校正, 翻訳, 構造化, 壁打ちフレーム
```

初期実装では **各カテゴリ2〜3本 × 主要カテゴリ**(計30本程度)を用意し、運用しながら追加する。

## 3. Router との接続

1. Classifier が `domain` を判定 → 該当カテゴリのプロンプト一覧(frontmatter のみ)を取得
2. タイトル・タグの類似度で最適プロンプトを選択(見つからなければ `共通/` を使用)
3. 変数を依頼文から抽出して差し込み、Agent のシステムプロンプトと合成して実行
4. 実行ログに `promptId` + `version` を記録 → 成功率を Dashboard で追跡 → 低成績プロンプトを改善

## 4. 運用ルール

- プロンプトの追加・修正も「依頼」として Router に投げられる(Knowledge Agent が Vault に書き込む)
- 税務・法務カテゴリの出力には自動で「※専門家の確認が必要」フッターを付与
- 月次で Reviewer Agent が「使用回数ゼロ」「成功率低」のプロンプトを棚卸し(改善提案として report)
